WHAT IS HTML?

HTML stands for HyperText Markup Language. It is the standard language used to build web pages.

HTML is a markup language. It describes the structure and content of a webpage using tags.

Think of HTML as the skeleton of a webpage. CSS controls the appearance and JavaScript controls behavior.

How does HTML work?

When you visit a website, your browser receives HTML from a server and converts it into a visual webpage.

  • Tags are written like <p>.
  • Most tags have opening and closing tags.
  • Tags can contain attributes.
  • Some elements such as <img> do not need closing tags.

THE BASIC SKELETON

Every HTML document normally starts with a structure similar to this: 

<!DOCTYPE html>
<html>

  <head>
    <title>My First Page</title>
  </head>

  <body>
    <h1>Hello World!</h1>
    <p>My first paragraph.</p>
  </body>

</html>
  • <!DOCTYPE html> tells the browser to use HTML5.
  • <html> contains the entire document.
  • <head> contains page information.
  • <body> contains visible content.

COMMON HTML TAGS

Tag Purpose
<h1> Main heading
<p> Paragraph
<a> Link
<img> Image
<div> Container
<span> Inline container
<ul> Unordered list
<li> List item
<button> Button
<input> Input field
